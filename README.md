
# AI Workforce Statements

Research project examining whether AI-attributed workforce reductions reflect actual technological substitution, organizational reorganization, or alternative firm-level explanations.

## Research Scope
- S&P 500 firms, 2018–2025
- Earnings-call workforce and AI statements
- Firm-level workforce changes

## Data Sources
- Earnings-call transcripts
- Revelio Labs
- Compustat
- CRSP and IBES
- SEC EDGAR

## Repository Structure
- `code/` — Data processing and analysis
- `docs/` — Research documentation
- `prompts/` — LLM extraction prompts
- `validation/` — Coding validation

## Data Access
Research data are stored separately from this repository. Restricted datasets are not publicly distributed.
